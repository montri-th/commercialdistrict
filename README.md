# CityMETER: Commercial District

**ย่านไหนเด่นเรื่องอะไร และอะไรมาด้วยกัน** — เดโมแผนที่ 3 มิติของย่านกลางทั่วประเทศไทย ที่เทียบแต่ละย่านกับจุดของ 16 ชุดข้อมูล CityMETER ทั้งหมวด Land · Location · Living เพื่ออธิบายจุดเด่นของย่านที่สัมพันธ์กัน พร้อมที่มาของทุกตัวเลข

- เว็บ: https://montri-th.github.io/commercialdistrict/ (ไทย) · https://montri-th.github.io/commercialdistrict/?lang=en (English)
- รุ่น 0.1.1 · 16 พฤศจิกายน 2569 · ขอบย่านจากทะเบียนย่านกลาง CityMETER (อ่าน 16 พ.ย. 2569 จากไฟล์ส่งออกของเจ้าของ ไม่เผยแพร่ชีต ที่อยู่ของชีต หรือเซลล์ของชีต) และชุดขอบย่านล่าสุดของเจ้าของ · ข้อมูลจุดจาก 16 เดโมของ CityMETER ตาม commit ที่บันทึก
- โค้ดต่อยอดจาก CityMETER · University (https://github.com/montri-th/university @ed2f350, citymeter-shell 0.6.1)
- หมวด: Location (คำสั่งเจ้าของ 16 พ.ย. 2569)

ข้อค้นพบแรก (snapshot ปัจจุบัน): **ย่านกลาง 343 ย่าน กินพื้นที่ 0.016% ของประเทศ แต่มีจุดขายแบรนด์หรู 69% ของที่มีพิกัด (237 จาก 345)** · สำนักงาน 42% · ร้านกล้อง 40% · ฟิตเนส 38% · ร้านกล้องกับแบรนด์หรูมาด้วยกันมากที่สุด (ρ 0.67 จาก 136 ย่าน)

> ชุดข้อมูล CityMETER Commercial District จากทะเบียนย่านกลาง CityMETER และ 16 ชุดข้อมูล CityMETER · อ่าน 16 พ.ย. 2569 · ขอบเขต ขอบย่านฉบับร่าง 343 ย่าน ใน 77 จังหวัด · วิธีนับ: `DATA_METHOD.md`

## ใช้งาน

```sh
npm start   # http://127.0.0.1:4173/
npm test    # unit tests บนข้อมูลจริง (node --test)
```

เป็น static site ไม่มี build step และไม่ต้อง `npm install` (Node ≥ 20 สำหรับ tests, Python 3 สำหรับ server) แผนที่โหลด MapLibre GL 5.6.2 จาก unpkg (ล็อก Subresource Integrity) และ tiles/glyphs จาก OpenFreeMap; basemap สร้างเองใน `js/shell/map-style.js` ถ้าแผนที่โหลดไม่ได้ ข้อค้นพบ แผง การเปรียบเทียบ และตารางยังใช้ได้ และหน้าบอกว่าส่วนไหนขาด

## สิ่งที่สำรวจได้

- **ข้อค้นพบแรก:** ชุดข้อมูลที่กระจุกในย่านมากที่สุด เทียบกับพื้นที่ที่ย่านกินจริง พร้อมตัวตั้งและตัวหาร ตามด้วยอีก 3 ชุด · เลือกจังหวัด — คิดในจังหวัดนั้น
- **ย่านที่เด่นหลายด้าน · สิ่งที่อยู่ในย่าน · อะไรมาด้วยกัน:** ย่านที่ติดกลุ่มบนหลายชุด · สัดส่วนของแต่ละชุดที่อยู่ในย่าน แยก Land · Location · Living · คู่ชุดข้อมูลที่ขึ้นลงด้วยกันในย่านทั่วประเทศ พร้อมย่านที่เด่นทั้งคู่
- **อ่านแผนที่ด้วย:** จุดเด่นของย่าน (สีและรูปทรงตามหมวดของจุดเด่นแรก) หรือชุดข้อมูลใดก็ได้ 16 ชุด (จำนวนต่อ ตร.กม. สเกล `density.area` ครบ 41 ระดับของ LDS) พร้อมอันดับย่านที่แน่นที่สุด
- **ย่านหนึ่งแห่ง:** แผนที่ 3 มิติจัดกรอบย่านและจุดของทุกชุดในขอบ · จุดเด่น (เทียบกับกลุ่มเทียบที่บอกจำนวนเสมอ) · จุดเด่นที่สัมพันธ์กัน (คู่ที่มาด้วยกัน และบทบาทที่ทะเบียนเสนอเทียบกับข้อมูล) · ทุกชุดข้อมูลพร้อมจำนวน ต่อ ตร.กม. และอันดับ · ย่านที่ส่วนผสมคล้ายกัน · ลิงก์ไปเดโมของชุดนั้นที่จังหวัดเดียวกัน
- **เปรียบเทียบ:** วางเทียบได้ถึง 4 ย่านในแถบล่างของแผนที่ วงกรอบ = แน่นที่สุดในกลุ่มที่เทียบ
- **รายชื่อ:** ตารางทุกย่านกับ 16 ชุดข้อมูล (ทางอ่านโดยไม่ใช้แผนที่)
- **ภาษา:** ไทยเป็นต้นฉบับ English ด้วย `?lang=en` (ชื่อย่านคงเป็นไทยตามทะเบียน)
- **ถามต่อใน Google:** ทุกมุมมองมีปุ่มถาม Google AI ด้วยคำถามที่ตรงกับสิ่งที่กำลังดู พร้อม Google Maps และ Street View · คำตอบของ Google ไม่ถูกนำมาเป็นข้อมูลในหน้านี้
- **เส้นทาง:** ประเทศไทย › จังหวัด › ย่าน ใช้รหัสจังหวัดเดียวกับ CityMETER production (`?at=BKK`) · `?f.neighborhood=CMN-TH-0001` · `?m=hotel` · `?cmp=…`

## ข้อมูล

- `data/neighborhoods.json` — ย่าน 343 ย่าน พร้อมจำนวน ความหนาแน่น อันดับ จุดเด่น และคู่ที่มาด้วยกันของ 16 ชุดข้อมูล · ชุดข้อมูลพร้อมขอบเขตการนับ ที่มา commit และ SHA-256 · รหัสที่ยังไม่มีขอบ 27 รหัส — `scripts/build-data.py`
- `data/boundaries.geojson` — ขอบย่านสำหรับแสดงผล (ย่อด้วย mapshaper โดยคงขอบร่วม) · `data/points.json` — จุดของแต่ละชุดในขอบย่าน 7,636 จุด
- `data/provinces.geojson`, `data/building-units/` — คัดลอกจาก montri-th/university @ed2f350 โดยไม่แก้ไบต์
- วิธีทั้งหมดและข้อจำกัด: `DATA_METHOD.md` · กลยุทธ์ผลิตภัณฑ์: `PRODUCT_STATEMENT.md` · สำหรับนักพัฒนา: `handoff/START_HERE.md` · สำหรับ agent: `AGENTS.md`, `llms.txt`
