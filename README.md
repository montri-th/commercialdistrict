## ใช้งาน

```sh
npm start   # http://127.0.0.1:4173/
npm test    # unit tests บนข้อมูลจริง (node --test)
```

เป็น static site ไม่มี build step และไม่ต้อง `npm install` (Node ≥ 20 สำหรับ tests, Python 3 สำหรับ server) แผนที่โหลด MapLibre GL 5.6.2 จาก unpkg (ล็อก Subresource Integrity) และ tiles/glyphs จาก OpenFreeMap; basemap สร้างเองใน `js/shell/map-style.js` ถ้าแผนที่โหลดไม่ได้ ข้อค้นพบ แผง การเปรียบเทียบ และตารางยังใช้ได้ และหน้าบอกว่าส่วนไหนขาด

## สิ่งที่สำรวจได้

- **ข้อค้นพบแรก:** ชุดข้อมูลที่กระจุกในย่านมากที่สุด เทียบกับพื้นที่ที่ย่านกินจริง พร้อมตัวตั้งและตัวหาร ตามด้วยอีก 3 ชุด · เลือกจังหวัด — คิดในจังหวัดนั้น
- **ย่านที่เด่นหลายด้าน · สิ่งที่อยู่ในย่าน · อะไรมาด้วยกัน:** ย่านที่ติดกลุ่มบนหลายชุด · สัดส่วนของแต่ละชุดที่อยู่ในย่าน แยก Land · Location · Living · คู่ชุดข้อมูลที่ขึ้นลงด้วยกันในย่านทั่วประเทศ พร้อมย่านที่เด่นทั้งคู่
- **อ่านแผนที่ด้วย:** จุดเด่นของย่าน (สีและรูปทรงตามหมวดของจุดเด่นแรก) หรือชุดข้อมูลใดก็ได้ (จำนวนต่อ ตร.กม. สเกล `density.area` ครบ 41 ระดับของ LDS) พร้อมอันดับย่านที่แน่นที่สุด
- **ย่านใหม่ในรุ่นนี้ (0.2.0):** หน้าแรกบอกขอบปิดใหม่ในทะเบียน 15 ย่าน และย่านที่พัก 37 ย่าน พร้อมปุ่มดูบนแผนที่ · ตัวกรอง “ย่านที่แสดง” เลือกขอบตามหลักเกณฑ์ทะเบียน ขอบร่างจากผลคัดที่พัก หรือใหม่ในรุ่นนี้
