# «รอบย่านนี้» — สัญญาและแผนของชั้นรอบย่าน

โฟลเดอร์นี้เป็นจุดเริ่มของงาน «ในย่านนี้» และ «รอบย่านนี้» ของ Commercial District (รุ่น 0.4.0) สำหรับคนและ AI coding agent ที่ทำต่อ อ่านไฟล์ตามลำดับนี้

| ไฟล์ | อ่านเพื่อ |
|---|---|
| `decisions.json` | คำสั่งเจ้าของ 25 พ.ย. 2569 08:15 น. แบบคำต่อคำ และทางที่รับของคำตัดสิน D-1 ถึง D-9 |
| `contracts.json` | สัญญาที่ต้องถือ: นิยามในย่านและรอบย่าน สถานะค่า 6 แบบ ชนิดหลักฐาน ชุดย่านอ้างอิงที่ตรึง กติกาชุดที่มีพิกัดไม่ถึง 90% กติการะดับ 5 ขั้น และ INV-01 ถึง INV-13 คำต่อคำ |
| `plan.json` | แผนลงมือของข้อเสนอฉบับ v1 ทุกไบต์ (SHA-256 `d5d37c7c3cbea3ddefb72f14e27cd989fe758f7a2e83ac2fa33de62a51f54f94`) · งาน NL-00 ถึง NL-14 และ NL-S1 พร้อม steps · acceptance · verify · doNot · prompt |
| `SOURCES.md` | ไฟล์ต้นทางทุกไฟล์พร้อม repository commit และ SHA-256 |
| `CHANGELOG.md` | สิ่งที่แต่ละรุ่นทำจากแผน และสิ่งที่ยังไม่ทำ |

## รุ่น 0.4.0 ทำอะไร

รอบ 1 ของแผน: NL-00 NL-01 NL-02 NL-04 NL-05 NL-06 NL-07

- `data/around.json` (`scripts/build-around.py`): ต่อย่าน ต่อชุดข้อมูลที่มีข้อมูลในจังหวัด จำนวนรายการนอกขอบที่ห่างจากเส้นขอบไม่เกิน 400 ม. และ 800 ม. วัดเส้นตรง · ระดับเทียบของแถว «ในย่านนี้» ในชุดย่านอ้างอิง 395 ย่าน · ศูนย์การค้าที่มีหน้า «รอบศูนย์นี้» ในขอบและรอบขอบ ผูกด้วยรหัส
- `data/rings/<รหัส>.json`: เส้นห่างจากขอบ 400 ม. และ 800 ม. สำหรับแผนที่เท่านั้น
- `js/around.js` · `js/panel.js`: แถว 4 ช่อง «ในย่านนี้» และตาราง «รอบย่านนี้» · `js/app.js` · `js/layers.js`: ตัวเลือกระยะ `f.around` และเส้นบนแผนที่ · หัวแผงแบบหน้าศูนย์การค้าเมื่อเปิดย่าน (D-5)
- จุดเด่นชนิดจำนวนและความหนาแน่นบอกจำนวนย่านที่ได้อันดับร่วม (NL-06)

## สร้างใหม่

```sh
# ไฟล์ 16 ชุดตามที่ data/neighborhoods.json ตรึง (datasets[].source) วางเป็น <dataset id>.json ในโฟลเดอร์เดียว
# นิคมอุตสาหกรรมใช้ industrialestate_dir/estates.json คู่กับ boundaries.geojson ของเดโมเดียวกัน
python3 -I scripts/build-around.py --sources <โฟลเดอร์ไฟล์ 16 ชุด> --shoppingcenter <clone ของ montri-th/shoppingcenter> --built-on <YYYY-MM-DD>
npm test
```

สคริปต์หยุดเมื่อ SHA-256 ของไฟล์ต้นทางไม่ตรง เมื่อจำนวนรายการที่อ่านได้ไม่ตรงกับ `data/neighborhoods.json` หรือเมื่อไฟล์รายการในขอบ (`data/records/`) ไม่ตรงกับ `rows[].c` รันซ้ำจากไฟล์เดิมได้ผลเดิมทุกไบต์

## ห้าม

- บวกจำนวนข้ามชุดข้อมูล บวกค่าในย่านกับรอบย่าน หรือบวกค่ารอบย่านข้ามย่าน (รายการเดียวอยู่รอบหลายย่านได้)
- เรียกค่ารอบย่านว่าพื้นที่ลูกค้า catchment คนเดิน ยอดขาย หรือความต้องการ
- ใส่ที่อยู่ ไฟล์ส่งออก หรือเซลล์ของชีตทะเบียนย่านใน repository (INV-11)
- เขียนชีตทะเบียนย่านโดยไม่มีคำสั่งเจ้าของสำหรับการเขียนครั้งนั้น
